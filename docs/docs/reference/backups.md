# Backups & Sharing

Your automation scenarios can represent hours of fine-tuning. Macrion makes it easy to export your scenarios into a standalone backup file, transfer them to a new device, or share them with others.

---

## 1. Exporting a Backup

1. Open **Macrion**.
2. Tap the menu in the top corner and select **Backup & Restore** (or the Backup tab).
3. Tap **Export Scenarios**.
4. Choose whether to export:
   - **All Scenarios**: Bundles every simple and smart scenario into one file.
   - **Selected Scenarios**: Pick specific scenarios to package together.
5. Choose a safe destination using Android's file picker (such as Google Drive, Nextcloud, or your Downloads folder).
6. The resulting file is saved with a `.zip` extension.

::: tip Keep Regular Backups
Before upgrading Android versions or updating Macrion, it is always best practice to create an export of your critical scenarios.
:::

---

## 2. Importing Scenarios

1. Transfer your `.zip` backup file to your phone.
2. Open Macrion ➔ **Backup & Restore**.
3. Tap **Import Scenarios**.
4. Select the `.zip` backup file.
5. Macrion will inspect the file and show you a preview of the scenarios it contains.
6. Tap **Confirm Import**. Any imported scenarios will appear directly in your scenario list.
