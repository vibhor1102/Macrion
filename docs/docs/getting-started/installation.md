# Installation & Setup

Installing Macrion takes only a minute. Because Macrion is a self-contained open-source application, it is distributed directly as an Android Application Package (APK).

---

## 1. Download the APK

Official releases are hosted on GitHub:

👉 **[Download Latest Macrion Release](https://github.com/vibhor1102/Macrion/releases)**

Under the **Assets** section of the latest release, you will see a few APK variants:

| Variant | Who is it for? |
| :--- | :--- |
| **`...-arm64-v8a.apk`** | **Recommended.** Virtually all modern Android smartphones and tablets use 64-bit ARM processors. Choose this variant for the smallest download size and best performance. |
| **`...-universal.apk`** | Contains code for all supported processor architectures. Choose this if you are using an older device or an Android emulator. |

::: tip Not sure which one to pick?
Download the `arm64-v8a` version. If your phone cannot install it, Android will simply tell you that the package is incompatible, in which case you can install the `universal` package instead.
:::

---

## 2. Installing on Android

1. Once the APK finishes downloading, tap the download notification or open your device's **Files** / **Downloads** app.
2. Tap the downloaded `.apk` file.
3. If this is your first time installing an app from your browser or file manager, Android will display a security prompt:
   > *"For your security, your phone is not allowed to install unknown apps from this source."*
4. Tap **Settings** on the prompt, then toggle **Allow from this source** to **On**.
5. Press the back button to return to the installer, then tap **Install**.

::: info Safety Note
Allowing installs from "unknown sources" simply means installing apps outside the Google Play Store. You can safely turn this permission off in your Android Settings after installation is complete.
:::

---

## 3. First Launch

Once installed, tap **Open** or find Macrion in your app drawer. 

On first launch, Macrion will prompt you to grant the necessary Android permissions. Continue to [Android Permissions Explained](./permissions) to understand what these permissions do and why they are needed.
