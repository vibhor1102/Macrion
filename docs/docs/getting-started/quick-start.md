# Quick Start Guide

In this 2-minute tutorial, you will create a simple scenario that taps a specific button repeatedly, launch the floating overlay, and run it inside another app.

---

## Step 1: Open Macrion & Create a Scenario

1. Open the **Macrion** app.
2. On the home screen, tap the **`+` (New Scenario)** button.
3. Choose **Simple Mode** (Position-Based).
4. Give your scenario a name (e.g., *"My First Auto-Click"*).

---

## Step 2: Add a Click Point

1. Tap **Add Action** or tap on the scenario list.
2. Select **Click (Tap)**.
3. You will see coordinates `(X, Y)` and timing options:
   - **Interval / Delay**: How long to wait before clicking (e.g., `1000 ms` for 1 second).
   - **Hold Duration**: How long the finger presses down (e.g., `50 ms` for a standard tap).
4. Save the action.

::: tip Placing Points Interactively
You don't need to guess coordinate numbers! When the floating overlay is open, you can tap the **Add Point** icon directly on top of your game or app to drop a tap target exactly where you want it.
:::

---

## Step 3: Start the Floating Overlay

1. Return to the scenario list in Macrion.
2. Tap the **Play / Launch Overlay** button next to your scenario.
3. Macrion will minimize, and the **Floating Control Panel** will appear on the side of your screen.

---

## Step 4: Run It Over Your App

1. Open the game or app you wish to automate.
2. If using interactive markers, drag the numbered target indicator directly over the button you want to tap.
3. Tap the green **Play (▶)** button on the floating overlay.
4. Macrion is now tapping for you!
5. Tap **Pause (⏸)** or **Stop (⏹)** on the overlay at any time to halt automation.
