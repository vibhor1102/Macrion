# Historical backup fixtures

This directory is reserved for small backup artifacts produced independently by released applications.

Do not regenerate historical fixtures with Macrion's current serializer. The first required artifact is a real
Klick'r `4.0.1-1-gd466f162` export containing a smart image scenario and a dumb scenario. Add the first stable
Macrion-native archive once its portable contract is finalized, then retain it unchanged.
